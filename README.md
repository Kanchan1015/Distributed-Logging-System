# Distributed Logging System

A Spring Boot application for storing and retrieving log entries through a REST API backed by MongoDB.

This repository has been cleaned up so the Maven project lives at the repository root.

## Tech Stack

- Java 17
- Spring Boot 3.2
- Spring Data MongoDB
- Maven
- MongoDB

## Prerequisites

Install the following before running the project:

- Java 17 or newer
- Maven 3.9 or newer
- MongoDB running locally on port `27017`

The application uses these default settings:

```properties
server.port=8081
spring.data.mongodb.host=localhost
spring.data.mongodb.port=27017
spring.data.mongodb.database=logsystem
```

You can override Spring Boot settings with environment variables, for example:

```bash
export SERVER_PORT=8081
export SPRING_DATA_MONGODB_HOST=localhost
export SPRING_DATA_MONGODB_PORT=27017
export SPRING_DATA_MONGODB_DATABASE=logsystem
```

## Setup

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd Distributed-Logging-System
mvn clean install
```

Start MongoDB before running the application. With Homebrew on macOS, one option is:

```bash
brew services start mongodb/brew/mongodb-community
```

If you prefer a one-off local MongoDB process:

```bash
mkdir -p /tmp/distributed-logging-mongodb
mongod --dbpath /tmp/distributed-logging-mongodb --bind_ip 127.0.0.1 --port 27017
```

Run the Spring Boot app:

```bash
mvn spring-boot:run
```

The API will be available at:

```text
http://localhost:8081
```

## API Quick Check

Create a log entry:

```bash
curl -X POST http://localhost:8081/api/logs \
  -H "Content-Type: application/json" \
  -d '{"message":"hello from the logging system"}'
```

Read all log entries:

```bash
curl http://localhost:8081/api/logs
```
